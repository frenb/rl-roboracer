The Default design is the trainer’s canonical reference set — seeded automatically at boot and intentionally not editable so jobs stamped with experiment_design_id=experiment-default always trace back to the same numbers. To customise, click Duplicate (top-right) for a pre-filled copy you can edit, or + New design for an empty form.
