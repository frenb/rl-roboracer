# Python deps for the MadScientist agent container.
#
# Tight pinning so a future pip-index outage or major-version bump (e.g.,
# pydantic v2 -> v3) doesn't break the container at the worst possible
# moment - mid research cycle, mid implementation, etc. Pin compatible
# ranges (~= for safety) rather than exact == so security patches still
# flow through.

# Mongo client. Match the trainer's pymongo major to avoid driver-version
# mismatches when running against the same db.
pymongo~=4.7

# Schemas + validation. Pydantic v2's BaseModel is the source of truth
# for proposal / research_note / judge_rubric_history shapes.
pydantic~=2.7

# Anthropic SDK - Claude calls for the MadScientist researcher + Judge.
anthropic~=0.39

# arXiv API client - paper metadata + abstracts. The researcher uses this
# to enumerate new papers since last cycle.
arxiv~=2.1

# HTTP for ad-hoc page fetches (semantic-scholar API, OpenReview, etc.).
# httpx supports both sync and async; we'll likely go sync first.
httpx~=0.27

# HTML parsing for web pages the researcher reads (paper landing pages,
# blog posts, openreview comments).
beautifulsoup4~=4.12

# Retry helpers for API calls that may be rate-limited (arxiv has gentle
# but enforced limits).
tenacity~=8.4

# Google APIs for the email bridge. Used by Phase 1's email_bridge.py
# to subscribe to Gmail Push notifications + read incoming threads.
# Pinning to a known-good range; Google releases these frequently but
# usually backward-compatible within minor versions.
google-auth~=2.30
google-auth-oauthlib~=1.2
google-api-python-client~=2.130

# Email sending. stdlib `smtplib` works for SMTP; `email-validator` adds
# RFC 5322 validation on addresses we send to.
email-validator~=2.2

# .env file loader so the orchestrator + workers can pick up secrets from
# a mounted .env without baking them into the image.
python-dotenv~=1.0

# Cursor SDK - Python bindings for Cursor cloud agents. Used by the
# Phase 1C-Full orchestrator to spawn code-writing agents that edit
# experiment_designs.SCHEMA + open PRs when a proposal carries
# proposed_schema_extensions.
#
# Public beta as of 2026-05-25 (current release: 0.1.5). Minor-version
# bumps are likely to change the API surface, so we PIN THE MINOR with
# ~= rather than the major - upgrades will require code review of
# rl_agent/madscientist/cursor_orchestrator.py before bumping.
#
# cursor_orchestrator.py uses a lazy try/except import so the rest
# of the system runs even without this package; the operator can
# still skip Phase 1C-Full by leaving CURSOR_API_KEY unset.
cursor-sdk~=0.1.5
